# Updating your Data Vault database — video tutorial sources

This video shows a **per-model Data Vault Update** plus **Begin/End Vault Update** for metrics.

The current recommended load is **Update resource definition group** (one action for every `.hdv` / `.hbv` / `.hdm` on the group, with optional Begin/End-style metrics built in): [Getting started — building an EDW](../../getting-started-edw.adoc), [Update resource definition group](../../update-resource-definition-group-action.adoc). Architecture: [Architecture](../../architecture.adoc).

Begin/End remain valid for a custom multi-action graph. See [Operations](../../operations.adoc).
