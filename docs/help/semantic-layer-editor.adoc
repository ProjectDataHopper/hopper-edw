= Semantic layer editor
:toc: macro
:toclevels: 2

toc::[]

Related: link:../semantic-layer.adoc[semantic layer].

Open a `.hsl` file or create one from the File menu. **Select dimensional model...** binds this layer to a `.hdm` and fills entities, measures, attributes, relationships, and default number/date format masks. The bound model path is shown in the label under the buttons. Several `.hsl` files may point at the same dimensional model.

**Create presentation...** opens an empty link:fact-crosstab-editor.adoc[crosstab editor] for this layer. If the tree has a fact selected, that fact is used; otherwise you pick one when the layer has more than one fact.

A toolbar above the tree has icons for **New**, **Open**, **Delete**, and **Rename**. **New** opens the same empty editor. **Open**, **Delete**, and **Rename** are enabled when a saved selection is selected. Double-click a selection, or press **Open**, to load that selection in the crosstab editor.

Select an attribute or measure in the tree to edit **Header**, **Format mask**, **Horizontal alignment**, **Vertical alignment**, **Aggregation** (measures; type `SUM`, `COUNT`, or `AVERAGE`, or pick one), **Totals** (measures), and **Description**. Edits are applied as you type. Save the `.hsl` with the usual Hop file save. Adding the field in the crosstab editor copies these choices.

Named selections created from the fact crosstab editor appear under **Selections**.
