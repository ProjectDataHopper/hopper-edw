= Source model settings
:toc: macro
:toclevels: 3

toc::[]

Related guide: link:../source-modeler-overview.adoc[source-modeler-overview].

**Edit model** sets defaults for the whole `.hsm` file: catalog connection, namespace, optional default database, and notes used when publishing tables, queries, JSON, and pipeline sources.

Individual cards still override catalog source names. Use **Push to catalog** on the toolbar after the model checks clean. **Check model** reports when a published catalog feed is stale vs the card you just edited. Saving the file also offers to publish those stale feeds unless you turn the reminder off (**Don't remind me after save**, or **Configuration → Data Vault 2.0**).
