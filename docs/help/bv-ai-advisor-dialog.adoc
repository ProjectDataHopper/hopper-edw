= Business Vault AI advisor
:toc: macro
:toclevels: 3

toc::[]

Related guide: link:../ai-advisory.md[ai-advisory.md].

Opens the Hop **AI Assistant** workbench bound to the open `.hbv` model: SCD2/PIT design, SQL business tables, dbt import, and generated pipelines.

Requires an **AI Provider** in Hop metadata and AI enabled under **Configuration → Plugins → AI Assistant**. Review any proposed edits before applying them. See link:../ai-advisory.md[AI advisory].
