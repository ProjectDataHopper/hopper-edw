Generate a Hopper presentation from a **semantic layer** (`.hsl`) bound to a dimensional star so you can try the warehouse query.

== Open the editor

On a `.hsl` file, **Create presentation...**. If more than one fact entity exists, pick one (or select the fact in the tree first). Right-click a fact table on a `.hdm` canvas → **Create presentation…** remains a shortcut that seeds an in-memory layer from that star. The action is hidden on dimensions, aliases, junk, range, and bridge tables.

== Layout

The **Sources** tree lists the selected fact entity and related entities from the `.hsl` (including role-playing aliases and junk dimensions). Range-dimension bands appear as columns on the fact; they are not joined. Fields you remove from the semantic layer do not appear here.

Four toolbar buttons above the tree add the selected column (or every column of a selected table) to:

* **Groups**
* **Horizontal dimensions**
* **Vertical dimensions**
* **Facts / KPIs** (with `SUM`, `COUNT`, or `AVERAGE`)

On desktop Hop GUI you can also drag a tree item onto a zone. Hop Web uses the toolbar only.

Check **Show horizontal totals** and **Show vertical totals** to add crosstab grand totals.

**Save selection** / **Open selection** store the zone layout on the current `.hsl`. Reopening **Create presentation...** from that layer reloads the last selection for that fact. Several `.hsl` files may bind to one `.hdm`.

**SQL** opens that query in Hop's database explorer, with a dialect limit of 1000 rows (`LIMIT` / `TOP`) applied after `GROUP BY`, so the cap limits groups rather than fact rows. The editor stays open.

**Show** builds that query (fact plus only the tables that contribute selected columns), generates a presentation in an isolated catalog (not saved in the Hop project), and opens the Hopper viewer (zoom, paging, SVG/PDF export, refresh). While the warehouse query runs, a progress dialog shows how many rows have been read. **Cancel** stops the query and closes the window. **Refresh** in the viewer runs the query again with the same dialog; cancelling that leaves the page that is already on screen. **Edit crosstab…** on that window returns here with the same selections.

The query groups by the columns in **Groups**, **Horizontal dimensions**, and **Vertical dimensions**, and aggregates each fact with the selected `SUM`, `COUNT`, or `AVERAGE`. The crosstab still rolls those rows into totals, and a group repeats the crosstab once per group value.

== Requirements

The dimensional configuration must have a **target database**. Connection fields (host, port, database, user, password) are resolved from the Hop environment when **Show** runs, so values like `'${DB_PASSWORD}'` become concrete in the isolated catalog. Extra JDBC options on the Hop connection (for example SQL Server `encrypt=false`) are not copied in this release.
