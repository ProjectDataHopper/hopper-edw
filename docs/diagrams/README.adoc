Use `!pragma layout smetana` in every file so Graphviz is not required.

== Render locally or via Maven

Maven (`generate-resources`) writes SVGs next to the screenshots:

[source,bash]
----
mvn generate-resources
----

Or with a PlantUML jar (same version as `plantuml.version` in the root `pom.xml`):

[source,bash]
----
java -jar plantuml.jar -tsvg -o ../images/diagrams .
----

Commit both the `.puml` change and the updated `.svg`.
